# ZN STORE

A modern, minimalist luxury fashion e-commerce website built with HTML, CSS, and JavaScript.

## About
ZN STORE is a front-end e-commerce website concept designed with a premium editorial aesthetic and a responsive layout.

## Features
- Modern luxury design
- Responsive mobile-friendly layout
- Product search and category filters
- Product quick view
- Shopping cart functionality
- Quantity management
- Cart persistence using localStorage
- PKR pricing display

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Status
Frontend demo project. Real payments, order processing, user accounts, and backend services are not connected.
